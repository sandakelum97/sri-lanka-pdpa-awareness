# Project name

**Chosen (31 Oct 2026): දත්ත සවිය · Datta Saviya** — "data strength / data support".

Why this one, judged as a brand for a public-interest initiative:
- *Saviya* is a familiar civic word in Sri Lanka (community-support programmes use it), so it reads as empowerment, not enforcement or compliance.
- Short and pronounceable in Sinhala, Tamil-speaker-friendly, and in English; works as a domain (dattasaviya.lk) and a social handle.
- Cannot be mistaken for a government or DPA service; contains no "official", "authority", "Lanka" or "gov" cues.
- Distinct from the previous working name "Mage Datta" (rejected by the owner as weak).

Alternatives considered: Datta Rakina (දත්ත රකිනා — "keep data safe"; more security than rights) · PDPA Pahasu (PDPA පහසු — leads with an acronym few know) · Datta Dekma (දත්ත දැක්ම — neutral) · Mage Datta (මගේ දත්ත — rejected).

Set in one file: `11-Website-Development/site/src/lib/site.ts`.

Before launch: Tamil rendering (தரவு சவிய?) checked with a Tamil speaker; .lk domain and social handles reserved; trademark search; confirm it does not clash with any existing Sri Lankan programme called Saviya.

# Project name

Working name (set in `11-Website-Development/site/src/lib/site.ts`): **මගේ දත්ත · Mage Datta** — "My Data". Puts the citizen first; two words anyone can say; works in both scripts.

Alternatives considered:
- **Datta Rakina (දත්ත රකිනා)** — "keep data safe"; slightly more "security" than "rights".
- **PDPA Pahasu (PDPA පහසු)** — "PDPA made easy"; clear, but leads with an acronym most people don't know.
- **Datta Dekma (දත්ත දැක්ම)** — "data view/vision"; neutral.

Checks before launch: Tamil rendering of the chosen name; .lk domain availability; trademark search; make sure it cannot be read as a government or DPA service.
